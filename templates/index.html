Student Performance Prediction System

A machine learning project exploring student sleep, screen time, lifestyle and academic performance.

About the Project

This project uses student data to train two supervised machine learning models. Linear Regression estimates numerical CGPA, while Logistic Regression predicts a CGPA category.

The models are built with scikit-learn, saved using joblib, and accessed through a FastAPI backend.

Predictions are estimates and do not prove that lifestyle factors cause particular academic outcomes.
